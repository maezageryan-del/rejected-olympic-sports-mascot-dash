Entry for the [Rejected Olympic Sports](https://make.fun/bounty/u-motasimfuad-rejected-olympic-sports-9d83e7da) bounty on make.fun: one funny single-line sport the Olympics rejected, short enough to fit in 200 characters.

## The entry

> The 100m Mascot Dash: athletes sprint in full mascot costume — gold to whoever finishes with the head still on, disqualified if anyone sees the human inside.

157 characters. Mascots are a real, beloved Olympic institution — and every mascot is a human, so a rule disqualifying anyone "caught being human" disqualifies the whole field. The twist lands in the final clause, in one read.

## How it runs

`main.ts` writes that single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) with no trailing newline, and fails loudly if the line ever leaves the 1–200 character gate.

```sh
node main.ts
```
